# RSVP Reader

A speed reader that shows one word at a time at a fixed point on screen, with the focus letter of each word highlighted in red.

## Getting started

1. Download `rsvp_reader.exe`.
2. Double-click it to run. No installation is needed.

Windows may show a warning the first time because the file is unsigned. Choose "More info", then "Run anyway".

## Using the reader

1. Paste or type text into the text box in the side panel, or load a file (see below).
2. Press Play, or press Space.
3. Adjust the speed and font size at any time, including while playing.

### Loading text

- Paste into the text box.
- Click Open file and choose a .txt or .md file.
- Drag a text file onto the window.

If you edit the text box, the new text is loaded the next time you press Play or Restart.

### Controls

| Control               | What it does                                                    |
| --------------------- | --------------------------------------------------------------- |
| Play / Pause          | Starts or pauses reading                                        |
| Restart               | Goes back to the first word                                     |
| WPM slider            | Reading speed, 100 to 1000 words per minute                     |
| Font size slider      | Size of the displayed word                                      |
| Focus position slider | Horizontal position of the red focus letter                     |
| Smart pacing          | Gives extra time to long words and punctuation                  |
| Show guide lines      | Shows or hides the small marks above and below the focus letter |
| Position slider       | Jump to any word in the text                                    |

The panel also shows the current word number, the total word count, and an estimate of the minutes remaining.

### Keyboard shortcuts

These work when the text box is not focused.

| Key         | Action                      |
| ----------- | --------------------------- |
| Space       | Play or pause               |
| Left arrow  | Back one word               |
| Right arrow | Forward one word            |
| Up arrow    | Speed up by 25 WPM          |
| Down arrow  | Slow down by 25 WPM         |
| Home        | Restart from the first word |
| Tab         | Hide or show the side panel |

You can also click the word display to play or pause.

## Notes

- Smart pacing adds time for words longer than six letters, a longer pause after sentence-ending punctuation (. ! ?), and a shorter pause after commas, semicolons, colons and dashes. Turn it off for a constant pace.
- If a word is too wide for the window, the font shrinks automatically for that word.
- When reading reaches the end, pressing Play starts again from the beginning.
- The thin red bar along the bottom of the display shows overall progress.
